## 🌿 Sobre o jogo

A **Arena da Tabuada 3D** é um jogo de matemática voltado para **estudantes que estão aprendendo ou revisando a multiplicação**. Em um jardim virtual em 3D, o jogador controla um robô e procura a resposta correta para cada operação entre os cristais coloridos espalhados pelo cenário.

A proposta é incentivar a prática da tabuada, a atenção e o raciocínio por meio de desafios. A cada acerto, o estudante se aproxima da próxima fase; a cada erro, tem uma oportunidade de tentar novamente e continuar aprendendo.

Pode ser utilizado como atividade complementar em sala de aula ou como uma forma de praticar em casa.

> **Explore o cenário, resolva os desafios e transforme cada tentativa em aprendizado.**

## 🎯 Como jogar

1. Leia a multiplicação apresentada na tela.
2. Encontre o cristal que mostra o resultado correto.
3. Complete **3 acertos por fase**.
4. Tente vencer as **5 fases** antes que o tempo ou a vida acabem.

| Desafio | Regra |
| :--- | :--- |
| ⏱️ Tempo | A partida começa com 60 segundos. |
| 💎 Alternativas | Cada rodada apresenta 6 respostas possíveis. |
| ❤️ Vida | O limite é de 10 erros. |
| 🚀 Fases | Os desafios de multiplicação avançam com o jogador. |
| 🔄 Recomeço | Clique em **Jogar Novamente** ao terminar. |

## ⌨️ Controles

| Tecla | Ação |
| :---: | :--- |
| **W A S D** ou **setas** | Mover |
| **Shift** | Correr |
| **Espaço** | Pular |

Use um **computador com teclado** e conexão com a internet para carregar os recursos 3D.

## 🛠️ Tecnologias

**HTML5 • CSS3 • JavaScript • Three.js • WebGL • GitHub Pages**

O cenário e as interações são renderizados com Three.js. O robô utiliza o modelo **RobotExpressive**, disponibilizado nos exemplos do Three.js. As bibliotecas e o modelo são carregados de fontes externas.
